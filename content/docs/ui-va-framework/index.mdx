## Phạm vi dự kiến

Tích hợp framework và giữ trải nghiệm người dùng nhất quán.

## Các bài trong nhóm

- [Tích hợp React](/docs/ui-va-framework/react) — Quản lý React roots, lifecycle, contexts và yêu cầu runtime khi ghép ứng dụng React.
- [Tích hợp Vue](/docs/ui-va-framework/vue) — Thiết kế mount/unmount, props và events cho một frontend Vue.
- [Tích hợp Angular](/docs/ui-va-framework/angular) — Quản lý bootstrap, providers, router và lifecycle khi tích hợp Angular.
- [Next.js, SSR và hydration](/docs/ui-va-framework/nextjs-ssr) — Đánh giá hỗ trợ theo phiên bản trước khi chọn federation, SSR hoặc composition cho Next.js.
- [CSS isolation](/docs/ui-va-framework/css-isolation) — So sánh CSS Modules, naming conventions, Shadow DOM và cách tránh style leakage.
- [Design system dùng chung](/docs/ui-va-framework/design-system) — Version tokens và UI packages để nhất quán giao diện mà không khóa release của các team.
- [Accessibility và UX xuyên ứng dụng](/docs/ui-va-framework/accessibility) — Giữ focus, keyboard navigation, loading states và thông báo lỗi nhất quán.
