## Phạm vi dự kiến

Tổ chức phát triển, kiểm thử các ranh giới và quan sát hệ thống.

## Các bài trong nhóm

- [Monorepo và multi-repo](/docs/kiem-thu-va-tooling/monorepo-multi-repo) — So sánh repository strategy, workspace tooling và quyền sở hữu pipeline.
- [Local development nhiều ứng dụng](/docs/kiem-thu-va-tooling/local-development) — Dùng dev orchestration, mocks và remote overrides để phát triển từng ứng dụng.
- [Unit và component tests](/docs/kiem-thu-va-tooling/unit-component-tests) — Kiểm thử logic, UI và lifecycle riêng của từng frontend.
- [Contract tests](/docs/kiem-thu-va-tooling/contract-tests) — Kiểm tra tính tương thích của module exports, props và event schemas.
- [Integration và E2E tests](/docs/kiem-thu-va-tooling/integration-e2e) — Kiểm thử user journeys đi qua nhiều frontend mà không tạo test suite quá dễ vỡ.
- [Logs, metrics và tracing](/docs/kiem-thu-va-tooling/observability) — Gắn tên ứng dụng, release version và correlation IDs vào lỗi cùng telemetry.
