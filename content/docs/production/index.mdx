## Các bài trong nhóm

- [Performance và bundle budget](/docs/production/performance) — Đo loading waterfalls, duplicated dependencies, Core Web Vitals và kích thước bundles.
- [Resilience khi remote lỗi](/docs/production/resilience) — Thiết kế timeout, error boundaries, fallback UI và giới hạn retry.
- [Security và trust boundaries](/docs/production/security) — Đánh giá remote code, CSP, supply chain và giới hạn isolation trong cùng JavaScript realm.
- [Dependency governance](/docs/production/dependency-governance) — Đặt quy tắc ownership, dependency upgrades, deprecation và compatibility windows.
- [Migration từ frontend monolith](/docs/production/migration) — Tách từng domain theo hướng tăng dần và xác định tiêu chí dừng hoặc quay lại.
