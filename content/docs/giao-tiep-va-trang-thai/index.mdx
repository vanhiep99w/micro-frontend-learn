## Phạm vi dự kiến

Giữ quyền sở hữu dữ liệu rõ ràng và giảm coupling giữa các frontend.

## Các bài trong nhóm

- [Hợp đồng giao tiếp](/docs/giao-tiep-va-trang-thai/contracts) — Thiết kế props, events và schemas có version cùng quy tắc tương thích.
- [Events và message bus](/docs/giao-tiep-va-trang-thai/events) — Trao đổi sự kiện với payload rõ ràng, cleanup và xử lý các event bị lặp.
- [State ownership](/docs/giao-tiep-va-trang-thai/state-ownership) — Phân định local state, shared state và tránh một global store điều khiển mọi remote.
- [Routing và navigation](/docs/giao-tiep-va-trang-thai/routing) — Chia quyền sở hữu URL, nested routes, deep links và browser history.
- [Data fetching và cache](/docs/giao-tiep-va-trang-thai/data-fetching) — Phân định API ownership, query cache, request deduplication và invalidation.
- [Authentication và session](/docs/giao-tiep-va-trang-thai/authentication) — Phối hợp login, session và logout mà không nhầm UI permissions với backend authorization.
