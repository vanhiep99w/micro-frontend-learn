## Phạm vi dự kiến

Học cơ chế runtime sharing và quản lý hợp đồng giữa host và remote.

## Các bài trong nhóm

- [Cơ chế Module Federation](/docs/module-federation/co-che) — Theo dõi remote entry, container và quá trình host lấy module từ remote.
- [Cấu hình exposes và remotes](/docs/module-federation/exposes-remotes) — Khai báo module công khai, địa chỉ remote và phân biệt cấu hình theo bundler.
- [Shared dependencies](/docs/module-federation/shared-dependencies) — Hiểu singleton, requiredVersion, eager và trade-off khi chia sẻ dependencies.
- [Dynamic remotes](/docs/module-federation/dynamic-remotes) — Nạp remote theo runtime manifest thay vì gắn cứng URL lúc build.
- [Types và contracts](/docs/module-federation/types-contracts) — Quản lý TypeScript types cùng hợp đồng runtime giữa các ứng dụng.
- [Version compatibility](/docs/module-federation/version-compatibility) — Thiết kế khả năng tương thích khi host và remote release ở thời điểm khác nhau.
