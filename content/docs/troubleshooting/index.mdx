## Các bài trong nhóm

- [Remote không tải được](/docs/troubleshooting/remote-khong-tai) — Kiểm tra URL, network, CORS, public path và remote entry khi loading thất bại.
- [Duplicate React và Invalid Hook Call](/docs/troubleshooting/duplicate-react) — Phân biệt React bị nạp trùng với vi phạm Rules of Hooks và runtime không tương thích.
- [Shared version mismatch](/docs/troubleshooting/shared-version-mismatch) — Debug share scope, requiredVersion và host/remote có dependency versions lệch nhau.
- [Lỗi routing và CSS](/docs/troubleshooting/routing-css) — Khoanh vùng deep links, history conflicts, style leakage và các assets không tìm thấy.
- [Cache lỗi thời và chunk errors](/docs/troubleshooting/stale-cache) — Debug entry cũ, artifacts đã bị xóa và chunk load errors sau deploy.
- [Checklist debug và FAQ](/docs/troubleshooting/debug-checklist) — Tổng hợp trình tự kiểm tra network, console, manifests, release versions và telemetry.
